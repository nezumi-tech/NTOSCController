# NT OSC Controller

VRChat内で特定のギミック（稼働状況のリアルタイム表示など）を動作させるための非公式OSC同期アプリケーションです。
指定したプロキシサーバーからステータス情報（JSONデータ）を取得し、VRChatのOSC機能を用いてアバターへパラメータを送信します。

## 主な機能

* **アバター着替えの自動検知**: VRChatからのOSC信号を受信し、対象のアバター（`NT_Sync_Enable` パラメータを持つアバター）を着用した時のみ通信を開始します。別のアバター着用時は通信処理を完全に停止するため、サーバーやPCへの無駄な負荷がかかりません。
* **バックグラウンド同期**: 自動同期ONの時、5分間隔でプロキシサーバーから最新のJSONデータを取得してVRChatへ送信します。
* **手動操作**: ウィンドウ上のボタンから「即時同期」や、「全点灯（ALL_ON）」「全消灯（ALL_OFF）」のトリガー送信が可能です。
* **タスクトレイ常駐**: アプリを最小化するとタスクトレイに格納され、VRChatプレイの邪魔になりません。

## 動作環境

* OS: Windows 10 / 11
* 必須ランタイム: **.NET 10.0 Desktop Runtime**

## インストールと初期設定

1. リリースページから最新のzipファイルをダウンロードし、任意のフォルダに解凍します。
2. `NTOSCController.exe` を実行します。
3. 初回起動時は設定ファイルがないため、自動で `config.json` の雛形が生成されてアプリが終了します。
4. 生成された `config.json` をメモ帳等で開き、ご自身のプロキシサーバーのURLを入力して保存してください。

**`config.json` の設定例:**
```json
{
  "DataFileUrl": "[https://your-proxy.workers.dev/datafile.json](https://your-proxy.workers.dev/datafile.json)",
  "MbsStatusUrl": "[https://your-proxy.workers.dev/mbs_status.json](https://your-proxy.workers.dev/mbs_status.json)"
}
```
Note: `config.json` は `.gitignore` に登録されており、リポジトリには含まれません。

## 使い方
1. VRChatを起動し、リングメニューの `Options > OSC` からOSC通信を Enabled にします。
2. 本アプリを起動します。
3. VRChat上で、対象のギミックが仕込まれたアバターに着替えます。
4. アプリのステータスが「アバター状態: ナノテラス装備中」に変わり、自動的にデータの取得・送信が開始されます。

## 開発者向け機能（デバッグダンプ）

Visual Studio等で Debugビルド して実行した場合のみ、VRChatから受信したOSCパケットの履歴が `osc_debug_dump.txt` に書き出される仕様になっています。
Releaseビルドではこの出力機能はコンパイル時に除外されるため、通常の利用においてパフォーマンスに影響を与えることはありません。
